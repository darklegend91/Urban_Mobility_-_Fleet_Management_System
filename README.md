# Urban_Mobility_-_Fleet_Management_System
This is the repository made for OOPS mini project given in Bridge Labz.

## Automated tests

The pytest suite is kept separately in `tests/`, with one test module for each
application module. See [`tests/README.md`](tests/README.md) for the complete
test structure, test inventory, coverage commands, and performance checks.

```bash
python -m pip install -r requirements.txt
python -m pytest
```
